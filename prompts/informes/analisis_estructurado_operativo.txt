El CV es una fuente SECUNDARIA: úsalo ÚNICAMENTE para corroborar información ya presente en las respuestas o para completar datos objetivamente faltantes que las respuestas no cubren (ej. nombres de empresas, fechas exactas de un empleo, puesto anterior, escolaridad, si nada de eso se mencionó en las respuestas). NUNCA uses el CV para contradecir, sobrescribir o "corregir" algo que el candidato sí respondió directamente — ante cualquier discrepancia entre el CV y las respuestas, siempre gana lo que el candidato respondió.

Cada respuesta viene con la pregunta que contesta ("Pregunta: ... / Respuesta: ..."). Lee siempre la pregunta para entender las respuestas cortas: un "Sí" o un "24 x 24" solo tienen sentido junto a lo que se preguntó (ej. Dentro de una misma sección puede venir dos veces el mismo dato: primero la nota que tecleó la reclutadora durante la entrevista y después un resumen automático de la llamada, que puede traer nombres de empresas, de personas o cifras mal transcritos. Este informe SOLO se genera para candidatos que ya se decidió avanzar en el proceso — nunca para candidatos rechazados. Por lo tanto siempre debe concluir con una recomendación de avance explícita (ver punto 5).
